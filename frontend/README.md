# Frontend Hotel Reservation Application

This is the frontend part of the Hotel Reservation Application. It is built using React and provides the user interface for interacting with the backend services.

## Getting Started

To get started with the frontend application, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd hotel-reservation-app/frontend
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   npm start
   ```

The application will be available at `http://localhost:3000`.

## Folder Structure

- `src/`: Contains the source code for the frontend application.
  - `App.js`: The main component that sets up routing and layout.
  - `components/`: Contains reusable components.
  - `pages/`: Contains different pages of the application.
